# Aufgabe
Client soll auf MyEndPoint zugreifen. MyEndPoint soll die Anfrage auseinander nehmen und die Befehle GET, POST, PUSH, 
PULL bzw. INSERT, UPDATE, GET, DELETE erkennen und ausführen.
